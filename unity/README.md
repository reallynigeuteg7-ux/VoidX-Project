# VoidX — Unity edition

Нативный перенос VoidX на **Unity 6.3 LTS (6000.3.25f1), URP 17.3**. Исходный WebView-прототип версии 0.3 находится в родительской папке и сохраняется отдельно.

## Запуск

Откройте эту папку в Unity Hub, выберите указанный редактор. Выполните **VoidX → Prepare project**, затем откройте `Assets/Scenes/VoidX.unity` и нажмите Play. Сцена запускает генератор арены, материалов, персонажей и мобильного Canvas. Все ресурсы доступны офлайн.

Управление: WASD, мышь, R — перезарядка, Q — смена оружия, Esc — пауза. Android: левый джойстик, обзор по правой стороне, удержание «Огонь»; во время удержания можно продолжать вести прицел. В меню доступны арсенал и параметры чувствительности, громкости и качества.

## Графика и игра

- URP: линейный цвет, мягкие каскадные тени, контактное затенение SSAO, отражение окружения, ACES, лёгкий bloom и полностью монохромная цветокоррекция.
- Детализированный промышленный двор: окна, ворота, контейнеры, трубы, фермы, маркировка, дальние здания и пыль. Статическая геометрия объединяется по материалам.
- Металлические материалы с микронормалями; винтовка и дробовик с планками, вентиляцией, оптикой, перчатками, отдачей и анимацией перезарядки.
- Пять волн, противники с обходом укрытий и анимацией ног, попадания в голову, видимые вражеские снаряды, аптечки и локальный рекорд.
- Настройки качества меняют разрешение рендера и тени. Это первая Unity-версия; геометрия пока процедурная, без сторонних моделей и motion capture.

## Сборка

Установите Android Build Support, JDK 17, SDK и NDK r27c. Скрипт использует инструменты на диске D; пути можно переопределить параметрами. APK содержит ARM64, ARMv7 и x86_64 для BlueStacks. Требуется Android 8+ и OpenGL ES 3.

```powershell
# Проверка маршрутов, коллизий и конфигурации
.\build-unity.ps1 -Target Validate

# APK с прежним ключом подписи; пароль задаётся локально, ключ в Git не входит
$env:VOIDX_KEYSTORE_PASSWORD = '<password>'
.\build-unity.ps1 -Target Android -Keystore 'D:\path\voidx.jks' -Output 'D:\VoidX-0.4.0.apk'

# Проверочная сборка для Windows
.\build-unity.ps1 -Target Windows -Output 'D:\VoidX-Windows\VoidX.exe'
```

Проверочный Windows player поддерживает `--voidx-smoke`: запускает настоящее меню и бой, проверяет движение, оружие, перезарядку и паузу, сохраняет скриншоты и результат. Папку вывода задаёт переменная `VOIDX_SMOKE_OUTPUT`. Этот сценарий отсутствует в обычной Android-сборке.

Версия Android: `com.voidx.game`, 0.4.0, versionCode 4. Для обновления поверх прототипа нужен прежний ключ. Рекорд Unity хранится в PlayerPrefs; запись из WebView-прототипа автоматически не переносится.

В Git входят Assets вместе с `.meta`, Packages и ProjectSettings. Library, Temp, Logs, Builds и ключи подписи исключены.
